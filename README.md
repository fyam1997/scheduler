# 排班表 Scheduler

一小時一格的排班工具，內部以半小時為精度（每格中間有虛線，可切半格）。零依賴，可以直接用 GitHub Pages 當純前端網站，也可以在本機跑一個小 server 存檔。

## 兩種用法

**純前端（GitHub Pages）**：整個 `public/` 就是網站，資料存在瀏覽器 `localStorage`，用 URL 分享。

**本機 server**：

```bash
npm start
```

開 http://127.0.0.1:4310 。可用 `PORT`、`HOST` 覆寫；資料檔在 `data/state.json`。

同一份 code 兩種環境都跑：`app.js` 會探測 `/api/state` 是否存在，有就用 server 存檔，沒有就自動退回 `localStorage`。

## 格子

- 表頭一小時一格，格中間有虛線代表半小時，所以實際精度是 30 分鐘。
- 同一個人連續做同一個工作時，格子會合併成一整塊並標上時數；換工作或休息才斷開。
- 右鍵點區塊可只清掉游標所在的那半小時，把連續工作切開。
- 整份時間表會自動縮到視窗寬度，不會橫向滾動；手機會再縮小字級。

## 排班操作

桌面：

- 先點工作卡再連續點格子快速填入（Esc 取消選取）。
- 點空格 → 選工作；點已排的格 → 換工作或清除。
- 點人手名 → 整天填同一工作；Shift+點人手名 → 清空整天。
- 工作卡上的「工作／休息」切換：休息不計工時，可用來滿足 Break／午餐條件。
- Ctrl+Z 復原（最多 60 步）。

手機（寬度 760px 以下）：

- 下方三個按鈕開「人手／工作／條件」抽屜；選工作後抽屜自動收起。
- 選了工作後底部條顯示「XX — 點格子填入」，直接點格子即可連續填。
- 點已排的區塊 → 選單可換工作、搬移或清空；「搬移」後點目標格放下。

## 條件

| 類型 | 例子 | 效果 |
| --- | --- | --- |
| 時段要有工作 | `11:00–14:00 收銀至少 1 人` | 該範圍每個半小時都要有足夠人手，不足時表頭標 ⚠ |
| 連續工作上限 | `連續工作 4 小時後要休息` | 某人連續工作超過 4 小時，人名標 ⚠ |
| 時段內要休息 | `11:00–14:00 內至少 1 小時休息` | 該範圍休息不足時人名標 ⚠ |

- 按時間表頭會自動把該小時填進條件表單（手機同時打開條件抽屜），再選工作與人數即可。
- 違反的項目會在頂部列出：表頭標 ⚠、人名標 ⚠，格子本身不標記；頂部的問題列表按下去會開啟對話框，列出全部警告（可逐項跳到相關時段），只有一個問題時直接跳到該時段。
- 沒有任何排班的人不會被檢查休息類條件。

## 其他

- **自動補缺**：只補「時段要有工作」的缺口，優先給已在做同一工作的人續做，避免碎片化。
- **匯出 CSV**：時間 × 人手，最後一欄列出所有條件。

## 分享連結

按「分享連結」會把整份班表編碼成 URL fragment：

```
https://<user>.github.io/scheduler/#d=j3.dZI_axtBEMW...
```

- 用 `#` 而非 query string：fragment 不會送到伺服器，不會進 access log。
- 編碼：緊湊 JSON → `deflate-raw` → base64url，前綴 `j3.` 表示格式版本。中文名字正常處理。
- 舊連結仍然可讀：`j2.`（緊湊 JSON，未壓縮）、`j1.`（完整 JSON）。
- 一次性快照：之後再改自己的班表，舊連結不會跟著變。
- 打開分享連結預設 **唯讀**：頂部顯示 banner，所有編輯入口停用。
- 按「複製這份來改」→ 清掉 URL 的 `#d=`、寫入自己的 `localStorage`、解除唯讀，之後就是自己的班表。
- 解碼時逐欄驗證（欄位類型、時間格式、id 是否存在、上限 99 人／36 工作），壞連結顯示提示而不是白屏。

體積參考：7 人 × 8 小時（80 個排班）約 515 個字元，同內容用 `j1.` 是 3.7 KB。

## 部署到 GitHub Pages

1. 建立 public repo，把這個資料夾推上去（branch `main`）。
2. repo Settings → Pages → Source 選 **GitHub Actions**。
3. `.github/workflows/pages.yml` 會在每次 push 時發佈 `public/`。

網址會是 `https://<user>.github.io/<repo>/`。

## 檔案

```
server.js        靜態檔案 + /api/state（本機用；資料檔壞掉會自動備份並重建）
public/          靜態網站本體
  index.html
  styles.css
  app.js
.github/workflows/pages.yml
data/state.json  本機模式自動產生（不進版控）
```
